# Installations

I am using pixi to install all global tools

```
pixi global install ruff
pixi global install basedpyright
pixi global install pyright
pixi global install lua-language-server
pixi global install ripgrep
pixi global install tree-sitter-cli
pixi global install lazygit
```

Then just clone this repo into `~/.config/nvim` and your are good to go.
